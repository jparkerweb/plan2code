# Plan2Code guides

The long-form guides that sit beside the [README](../README.md). The README is the short version: what Plan2Code is and how to install it.

## Using

- [walkthrough.md](walkthrough.md): one feature from a sentence to archived specs, session by session.
- [web-console.md](web-console.md): the web console guide, from the dashboard to the last sign-off.
- [steps.md](steps.md): what each of the six steps asks, writes and hands on.
- [launcher.md](launcher.md): the `plan2code` command, its flags, and using an agent other than Claude Code, Devin or Codex.
- [activities.md](activities.md): the small games behind the die in the console's top bar.
- [status-line.md](status-line.md): the optional three-line Claude Code status bar.

Also: [QUICK-REFERENCE.md](../QUICK-REFERENCE.md) (the one-page card) and [docs/desktop-app.md](../docs/desktop-app.md) (the desktop app and the Implementation Loop).
